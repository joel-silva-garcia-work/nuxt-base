# Architecture Skill

Antes de proponer arquitectura:
1. Inspeccionar la existente.
2. Identificar módulos y dependencias.
3. Identificar límites de responsabilidad.
4. Identificar flujo de datos.
5. Identificar riesgos.

Priorizar:
- simplicidad
- bajo acoplamiento
- alta cohesión
- testabilidad
- seguridad
- mantenibilidad
- compatibilidad con el proyecto
