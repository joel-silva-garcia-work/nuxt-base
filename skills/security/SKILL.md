# Security Skill

Analiza amenazas según el contexto.

Checklist:
- authentication
- authorization
- session/token handling
- CSRF
- XSS
- injection
- SSRF
- secret exposure
- insecure logging
- validation
- error disclosure
- dependency/configuration risk

Para cada hallazgo:
1. causa
2. impacto
3. corrección
4. prueba de regresión

No expongas secretos ni implementes controles inseguros por conveniencia.
