---
name: Review Code
description: Revisa código buscando defectos, riesgos y mejoras.
invokable: true
---

Realiza una revisión técnica del código seleccionado.

Prioridad:
1. Bugs y regresiones.
2. Seguridad.
3. Errores de lógica.
4. Contratos API.
5. Persistencia.
6. Rendimiento.
7. Manejo de errores.
8. Tipado.
9. Mantenibilidad.
10. Tests faltantes.

Para cada hallazgo indica:
- severidad
- ubicación
- problema
- impacto
- corrección recomendada

No propongas refactorizaciones cosméticas salvo que aporten valor.
