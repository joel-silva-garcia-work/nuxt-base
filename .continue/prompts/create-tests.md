description: Genera pruebas a partir de requisitos o código.

---

Genera pruebas para el comportamiento indicado.

Incluye cuando corresponda:
- happy path
- validaciones
- errores
- autorización
- límites
- estados vacíos
- persistencia
- regresiones
- e2e

Usa el framework de pruebas ya instalado en el proyecto.
No introduzcas otro framework sin justificarlo.
