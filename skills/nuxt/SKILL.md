# Nuxt Skill

Usar cuando la tarea afecte a frontend Nuxt/Vue.

## Método
1. Identificar versión de Nuxt.
2. Revisar estructura existente.
3. Identificar SSR/client boundaries.
4. Reutilizar composables, componentes y servicios.
5. Implementar estados loading/error/empty/success.
6. Verificar hydration y runtimeConfig.
7. Añadir pruebas apropiadas.

## Reglas
- Composition API y TypeScript.
- No exponer secretos.
- No duplicar lógica de negocio.
- Mantener componentes pequeños.
- Preferir patrones existentes del proyecto.
