# QA Skill

Transforma requisitos en comportamiento verificable.

Cobertura:
- criterios de aceptación
- reglas de negocio
- validaciones
- restricciones
- happy path
- negative path
- boundary cases
- permisos
- errores
- persistencia
- regresiones
- e2e

Cada prueba debe tener un objetivo claro y un resultado observable.
No inventar UI ni requisitos.
