---
name: Security Review
description: Revisión de seguridad del cambio o módulo seleccionado.
invokable: true
---

Revisa el código desde una perspectiva defensiva.

Comprueba:
- autenticación
- autorización
- validación
- gestión de secretos
- sesiones/tokens
- CSRF
- XSS
- inyección
- SSRF
- exposición de errores
- logging
- dependencias
- configuración

Clasifica hallazgos por severidad y proporciona correcciones seguras.
No describas procedimientos ofensivos innecesarios.
