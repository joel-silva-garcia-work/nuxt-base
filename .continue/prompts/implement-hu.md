Implementa la HU proporcionada.

Proceso obligatorio:
1. Analiza requisitos y restricciones.
2. Inspecciona el workspace.
3. Identifica arquitectura y patrones existentes.
4. Determina archivos afectados.
5. Identifica cambios de frontend, backend, API y persistencia.
6. Identifica seguridad y validaciones.
7. Implementa el cambio mínimo necesario.
8. Añade/actualiza pruebas.
9. Ejecuta verificaciones disponibles.
10. Revisa el diff y busca regresiones.
11. Resume archivos, decisiones, pruebas y pendientes.

No inventes APIs ni dependencias.
