# Azure DevOps Skill

Cuando el requisito pida casos de prueba:
- usar nombres claros y verificables
- separar casos independientes
- mantener pasos reproducibles
- usar resultados esperados observables
- distinguir precondiciones de pasos
- incluir datos necesarios
- evitar texto ambiguo

Si se requiere un formato específico, respetarlo exactamente.
No inventar IDs, rutas, usuarios o contenido que no esté disponible.
