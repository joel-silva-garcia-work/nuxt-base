---
name: Create QA Cases
description: Genera casos de prueba QA detallados a partir de una HU.
invokable: true
---

Analiza la HU y genera casos de prueba independientes.

Para cada caso:
- nombre
- precondiciones
- pasos
- resultado esperado
- datos necesarios
- prioridad
- tipo: positivo, negativo, límite o regresión

Usa textos visibles exactos si fueron proporcionados.
No inventes textos de UI.
Cubre criterios de aceptación y restricciones.
