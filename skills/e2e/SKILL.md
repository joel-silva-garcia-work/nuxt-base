# E2E Skill

Construye escenarios desde la perspectiva del usuario/sistema.

Verifica:
- precondiciones
- navegación
- datos
- permisos
- API
- persistencia
- UI observable
- mensajes
- errores
- cleanup

Evita depender de detalles internos cuando el comportamiento externo sea suficiente.
