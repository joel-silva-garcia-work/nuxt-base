# TypeScript Skill

- Aprovecha tipos existentes.
- Evita any salvo justificación.
- Prefiere tipos explícitos en fronteras públicas.
- Usa unions/discriminated unions cuando representen estados.
- Evita casts innecesarios.
- No ocultes errores con @ts-ignore sin explicación.
- Mantén funciones pequeñas.
- Identifica null/undefined explícitamente.
- Comprueba errores de compilación después de cambios relevantes.
